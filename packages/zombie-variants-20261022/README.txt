Bodycam Zombie Variants 0.1.0 candidate

Close Bodycam completely. Run Install.ps1 from PowerShell. For an existing variant installation, use Install.ps1 -UpdateExisting; its previous directory is retained as a backup outside Mods. The installer verifies versions and checksums, refuses a running game, and installs only BodycamZombieVariants. Start the game normally afterward. Existing Z-Deathmatch files are never replaced.

This candidate passed offline checks. Actual gameplay, Steam lobby publication and a guest without mods still need live acceptance. See BodycamZombieVariants/README.md.
